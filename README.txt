# AgriNest Agriculture Marketplace

A college-project agriculture e-commerce website inspired by the uploaded AromaCraft reference structure.

## Included
- Home page and hero section
- Categories
- Product catalog
- Search, category, type and price filters
- Product details
- Wishlist
- Cart
- Checkout
- Demo customer/admin login
- User profile
- About and Contact
- Admin dashboard with products/orders/customers
- LocalStorage for demo cart, wishlist and orders
- Responsive HTML/CSS/JavaScript UI

## Run
Open `index.html` in a browser. For best results, use VS Code + Live Server.

## Note
This is a frontend/client-side college project. The demo data is stored in browser LocalStorage; it is not connected to a real server/database.
